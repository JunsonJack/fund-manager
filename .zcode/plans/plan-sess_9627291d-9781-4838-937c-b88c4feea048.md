## 计划：初始化 Git 仓库

当前项目已有完整的 uni-app + Vue 3 代码，但未初始化 Git 仓库。将执行以下步骤：

### Step 1：创建 `.gitignore` 文件
针对 uni-app + Vue 3 + 微信小程序项目，忽略以下内容：

- `node_modules/` — 已安装的依赖（2.6+ MB）
- `dist/` — 编译输出（微信小程序产物）
- `project.private.config.json` — 微信开发者工具私有配置
- `src/cloudfunctions/*/node_modules/` — 云函数依赖（预防性）
- `src/cloudfunctions/*/package-lock.json` — 云函数锁文件（预防性）
- `*.log` — npm 日志（预防性）
- `.env` / `.env.*` — 环境变量（预防性）

### Step 2：初始化 Git 仓库
```bash
git init
```

### Step 3：暂存所有文件
```bash
git add .
```

### Step 4：创建首次提交
```bash
git commit -m "init: 智投汪星人 AI 基金管理小程序项目初始化"
```
