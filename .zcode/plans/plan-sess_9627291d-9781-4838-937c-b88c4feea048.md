## 版本号自动累加功能

### 实现方案

#### 1. `version.json` — 版本号存储
```json
{ "version": "1.0.0", "build": 1 }
```

#### 2. `bump-version.js` — 自增脚本
- 读取 `version.json`
- patch 版本号 +1（1.0.0 → 1.0.1）
- 同步更新 `manifest.json` 中的 `versionName` 和 `versionCode`
- 将版本信息写入 `src/config/version.js` 供页面引用
- 输出当前版本号

#### 3. `package.json` — 构建流程
```json
"build:mp-weixin": "node bump-version.js && vite build --mode production"
```

#### 4. `src/config/version.js` — 运行时版本常量
自动由 bump-version.js 生成，页面通过 import 引用

#### 5. 设置页面底部 — 展示版本号
在 `pages/settings/index` 底部用小字灰色显示 `v1.0.1 (2)`
