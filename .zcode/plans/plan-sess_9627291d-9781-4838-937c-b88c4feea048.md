## 板块行情双Tab实现计划

### 需求
板块行情区域拆分为 **热门板块** 和 **领涨板块** 两个Tab，数据均通过东方财富API获取。

### 改动清单

#### 1. `src/utils/fund-api.js` — 新增API
- `getHotSectors()` — 按成交额降序获取热门板块（`fid=f6&po=1`）
- `getLeadSectors()` — 按涨跌幅降序获取领涨板块（`fid=f3&po=1`）

#### 2. `src/store/modules/market.js` — 新增状态和action
- state: `hotSectors: []`, `leadSectors: []`
- getters: `getHotSectors`, `getLeadSectors`
- mutations: `SET_HOT_SECTORS`, `SET_LEAD_SECTORS`
- actions: `fetchHotSectors`, `fetchLeadSectors`（三级降级：HTTP → 云函数 → 空数据）
- 修改 `refresh` 并行请求两个新action

#### 3. `src/pages/index/index.vue` — 双Tab UI
- 添加 `currentSectorTab` 切换状态（`hot` / `lead`）
- 热门板块：显示名称 + 涨跌幅 + 成交额
- 领涨板块：显示名称 + 涨跌幅

#### 4. `src/cloudfunctions/fundData/index.js` — 云函数新增action
- `getHotSectors`、`getLeadSectors`
